# PearlUI project guidance

PearlUI is a client-side Luau UI library. The reusable skill is
`skills/pearl-ui/SKILL.md`; read it for PearlUI-specific integration and
maintenance, then load only the relevant references.

- Source of truth: `src/PearlUI.luau`; `dist/` is generated by `python tools/build.py`.
- Public contract: `docs/API.md`; defaults: `defaults/PearlUI.defaults.json` and `docs/Defaults.md`.
- Regenerate portable skill references with `python tools/sync_skill.py` after
  changing API/default docs or canonical integration/config guides.
- Validate metadata with `python tools/validate_metadata.py`. The skill can be
  checked with the installed skill-creator validator when available.
- Preserve stable IDs, old config banks, custom accents and adapter boundaries.
  Keep game-specific config scope separate from a library constructor's global default.
- Core UI code must not depend on executor file APIs. The optional file adapter
  is in `examples/FileStorage.luau`; DataStore work belongs on the server.
- Do not commit real settings files, credentials, local screenshots or test
  client IDs. Do not turn historical validation counts into claims for new edits.
- Keep Lucide/Feather copyright and license notices with the embedded icon data.

Run checks appropriate to the edited surface. Publishing or live application
requires task authorization; this file does not add authorization or impose
extra approval on already-authorized reversible work.
